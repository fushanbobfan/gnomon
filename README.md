# gnomon

A sundial and sun-path lab in the browser. Pick a place, a date and a time
and see where the sun stands in the sky, the shadow a vertical pin casts on
level ground, and how the shadow's path changes through the year.

## Quick start

Open `index.html` through any static server, or run:

```bash
npm run serve
# then visit http://localhost:8080
```

Run the tests with `npm test` (Node 20 or later, no dependencies).
